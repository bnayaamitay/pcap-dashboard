# PCAP Dashboard (V1)

Computer Networks course – Assignment 1, Part C.

A Python dashboard that loads a PCAP/PCAPNG file, extracts HTTP traffic on its own
(packet counts, endpoints, protocols, request/response transactions), and uses an AI model
to answer free-form questions, **based only on the data already extracted**, together with
the evidence (frames, timestamps).

> Installation and run instructions will be added as the project is built.
